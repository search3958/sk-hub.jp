ログイン

増やさない。

ログインは Google か GitHub のアカウントで。SK がパスワードを発行・保存することはありません。2 段階認証などの安全の設定も、それぞれのアカウントのものがそのまま守ってくれます。1 つのアカウントに両方をつないでおくこともできます。

プライバシー

保存するのは、
最小限。

アカウントに保存するのは、ログインと、あなたが使うサービスに必要なものだけです。

  • Google・GitHub・LINE・Kakao のアカウントのパスワード
  • 閲覧履歴・検索語
  • Gmail・Google ドライブ・GitHub のリポジトリなどの中身

保存する情報

  • ログインに使うアカウント（Google・GitHub）の識別子・名前・メールアドレス・アイコン、LINE・Kakao の識別子・名前・アイコン、登録したパスキーの公開鍵（ログインに使います。LINE・Kakao からメールアドレスは受け取りません。指紋・顔などの情報は端末から出ません）
  • アカウントの作成日と、規約に同意した日
  • プロフィール（決めた場合の表示名とアイコン）と、端末のあいだで同期する設定（表示言語・アプリの設定）
  • SK からのお知らせ（お問い合わせへの返事など）
  • 使ったブラウザのタイムゾーン（おおまかな地域）とサポートID（お問い合わせ・不正な利用への対応に使います）
  • 使ったサービスのデータ（例: 管理コンソールの管理グループ）

保護者の同意が必要な年齢は、住んでいる地域によって異なります。正確な内容は SK Hub Systems アカウント規約 と SK プライバシーポリシー をご覧ください。
