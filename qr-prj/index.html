使い方
1QR Code Dropで送信側がファイルを選び、表示されたQRコードを受信側のカメラで読み取ります。
2送信開始を押すとQRコードが順番に切り替わります。受信側は完了までカメラを向けてください。
3QR Web Dropでは接続QRを交換した後、WebRTCでファイルを直接送信できます。
4選択したファイルはこの端末の転送履歴に保存され、後から再送信できます。
