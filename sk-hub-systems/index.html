SK's Toolbox のオンライン同期

SK にも、
読めない同期。

Todo・Memo・Countdown などを、スマホやパソコンのあいだで同期できます。データは端末で暗号化してから保存するので、中身を読めるのはあなただけ。使うかどうかは自由で、最初はオフです。

最初は、オフ。

同期を始めるまで、Toolbox のデータは端末の中だけ。SK Hub Systems アカウントで Toolbox に接続し、Toolbox の設定で「同期を始める」を選んだ端末だけが同期します。

鍵は、手元に。

あなたが決めた同期用のパスフレーズから端末で鍵を作り、AES-GCM（256 ビット）で暗号化します。パスフレーズと鍵は、サーバーに送りません。

アプリごとに選べる。

Toolbox の設定・Todo・Memo の文章・Countdown・Calc の履歴から選べます。Memo の画像と Clock は同期しません。

いつでも、消せる。

Toolbox の設定やアカウントのページから、アカウントに保存した同期のデータをいつでも削除できます。端末のデータは消えません。

  1. 1

    アカウントで Toolbox に接続

    Toolbox の設定の「オンライン同期」から、SK Hub Systems アカウントでログインして接続します。

  2. 2

    パスフレーズを決める

    8 文字以上の同期用のパスフレーズを決めると、同期が始まります。

  3. 3

    ほかの端末でも同じパスフレーズを

    パソコンやタブレットで同じパスフレーズを入れると、データがまとまります。変えた内容は、少したつと自動で同期します。

扱う情報（同期を使う場合）

  • 同期を選んだアプリのデータ（端末で暗号化したもの。大きさに上限があります）
  • パスフレーズが合っているかを確かめるための暗号文と、鍵を作るための値（パスフレーズそのものは保存しません）
  • 最後に同期した日時

パスフレーズを忘れると、アカウントに保存したデータは SK にも元に戻せません（端末のデータは消えず、同期をやり直せます）。正確な内容は SK Hub Systems アカウント規約 と SK プライバシーポリシー をご覧ください。

プライバシー

閲覧履歴は、
集めない。

見守りに必要な情報だけを扱います。広告、販売、第三者への提供、行動の分析には使いません。

  • 閲覧履歴
  • 検索語
  • 見たページの内容
  • ブロックされたページの記録
  • 入力した内容
  • 位置情報

扱う情報（遠隔管理を使う場合）

  • Y-FILTER. の設定内容（アクセスコードは元に戻せない形に変換したもの）
  • 端末の状態（最終接続日時、日ごとの利用時間と上限）
  • 端末の情報（Y-FILTER. のバージョン、ブラウザの種類、OS）
  • 接続の情報（端末名、匿名の端末 ID）
  • リクエストを送ったときの、そのページの URL とメッセージ
  • 管理者の Google アカウントの識別子・メールアドレス・表示名

正確な内容は SK Hub Systems 利用規約 と SK プライバシーポリシー をご覧ください。
