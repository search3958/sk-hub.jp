SK Hub Systems アカウント

ログインアカウントを作成

SK のサービスを、ひとつのアカウントで。いつもの Google や GitHub のアカウントで入れて、パスワードを新しく作る必要はありません。

Google か GitHub のアカウントでログインします。はじめての方も、このボタンからアカウントを作成できます。

はじめての方は

アカウントをお持ちの方は

  • ひとつのアカウントで管理コンソールも、これからのサービスも同じアカウントで使えます。
  • 保存するのは最小限ログインに必要な情報と、規約に同意した日だけ。閲覧履歴は集めません。
  • いつでも削除できるこのページから、アカウントとサービスのデータをまとめて削除できます。

アカウントを作成

このアカウントで SK Hub Systems アカウントを作成します。内容を確認して、同意してください。

保存する情報

  • ログインに使うアカウント（Google・GitHub）の識別子・名前・メールアドレス・アイコン、LINE・Kakao の識別子・名前・アイコン、登録したパスキーの公開鍵（ログインに使います。LINE・Kakao からメールアドレスは受け取りません。指紋・顔などの情報は端末から出ません）
  • アカウントの作成日と、規約に同意した日
  • プロフィール（決めた場合の表示名とアイコン）と、端末のあいだで同期する設定（表示言語・アプリの設定）
  • SK からのお知らせ（お問い合わせへの返事など）
  • 使ったブラウザのタイムゾーン（おおまかな地域）とサポートID（お問い合わせ・不正な利用への対応に使います）
  • 使ったサービスのデータ（例: 管理コンソールの管理グループ）

保存しない情報

  • Google・GitHub・LINE・Kakao のアカウントのパスワード
  • 閲覧履歴・検索語
  • Gmail・Google ドライブ・GitHub のリポジトリなどの中身

    使えるサービス

    Y-FILTER. 管理コンソール Y-FILTER. を入れた端末の設定を、まとめて管理できます。 MALU 単語帳と、検索履歴の端末のあいだの同期が使えます。 Nagi 集中の記録と 1 日の目標を、端末のあいだで同期できます。 SK's Toolbox Todo・Memo などを、暗号化して端末のあいだで同期できます（任意）。
    これからのサービス 新しいサービスも、このアカウントで使えるようになります。

    設定

    表示言語と、アプリの設定は、このアカウントでログインしている端末のあいだで自動でそろいます。

    表示言語 サイト・MALU・SK's Lab の言語。ここで変えると、ほかの端末にも反映されます。
    アプリの設定 MALU（既定の辞書・結果の開き方・テーマ）と QR Drop（テーマ・転送や履歴の設定）。検索履歴・転送したファイルは同期しません。
