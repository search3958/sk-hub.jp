SK プライバシーポリシー
制定日：2026年9月25日

第一条 基本方針
1.SK（以下「開発者」といいます。）は、SK 利用規約に定める本サービスにおいて、ユーザーの情報を本ポリシーに従って取り扱います。
2.開発者は、本サービスの提供に必要な範囲でのみ情報を取り扱います。取り扱う情報を、広告、販売、第三者への提供、本サービスの外での行動の追跡に利用することはありません。第四条の二のアクセス解析は、許可した人についてのみ行います。
3.Y-FILTER.、SK Hub Systems 及び SK Hub Systems アカウントにおける情報の取り扱いの詳細は、「Y-FILTER. 利用規約およびプライバシーポリシー」、「SK Hub Systems 利用規約」及び「SK Hub Systems アカウント規約」に定めます。これらと本ポリシーの内容が異なる場合は、そのサービスについてはそれぞれの定めが優先します。

第二条 サービスごとの概要
(a) 本サイト（SK's Lab のツールを含みます。）・MALU・Nagi・Y-FILTER. の管理コンソール：第三条のアクセスチェックの情報を取り扱います。MALU の検索語・検索履歴・設定は、ブラウザの中だけに保存し、送信しません。ただし、SK Hub Systems アカウントでログインしている場合は、SK Hub Systems アカウント規約に定めるとおり、MALU の設定を同期し、MALU に接続したときは単語帳に保存した言葉を、検索履歴の同期を有効にしたときは検索履歴を、本人のアカウントに保存します。
(b) Y-FILTER.：フィルタリングはブラウザの中で行い、閲覧履歴や検索語を開発者に送信しません。
(c) SK Hub Systems：Y-FILTER. の遠隔管理機能を利用する場合、または Y-FILTER. を自分の端末として SK Hub Systems アカウントにつないだ場合に限り、設定内容や端末の状態、設定のバックアップなどを保存します。
(d) お問い合わせ：お問い合わせフォームに入力された内容を SK Hub Systems に保存します。
(e) SK Hub Systems アカウント：アカウントを作成した場合に限り、ログインに使うアカウント（Google・GitHub・LINE・Kakao）の情報（識別子・名前・アイコン。Google・GitHub はメールアドレスも。LINE・Kakao からメールアドレスは受け取りません。パスキーを登録した場合はその公開鍵など。指紋・顔などの情報は受け取りません）と、規約に同意した日などを保存します。ログインして使ったブラウザのタイムゾーン（おおまかな地域）とサポートIDも、利用の記録として保存します。
(f) Nagi：集中の記録（集中を始めた時刻と集中した時間）と設定は、ブラウザの中だけに保存し、送信しません。ただし、SK Hub Systems アカウントで Nagi に接続したときは、集中の記録と 1 日の目標を本人のアカウントに保存します。何を勉強したかや、閲覧しているサイトは記録しません。
(g) SK's Toolbox：Clock・Calc・Memo・Todo・Countdown・Timetable・Roulette のデータと設定は、ブラウザの中だけに保存し、送信しません。ただし、SK Hub Systems アカウントで SK's Toolbox に接続し、オンライン同期を始めたときは、同期を選んだアプリのデータを、利用者が決めた同期用のパスフレーズで端末で暗号化してから本人のアカウントに保存します。暗号を解く鍵は端末の中にだけあり、開発者は内容を読み取れません。Memo の画像は送信しません。また、開発者が Timetable で時間割を配信する場合は、配信先として開発者が入力したメールアドレスと配信する時間割を SK Hub Systems に保存し、そのメールアドレスの SK Hub Systems アカウントでログインした本人に時間割を表示するためだけに使います。配信先の人どうしには表示せず、配信をやめると削除します。招待コードで配信に参加した場合、又は配信先の人が配信された時間割を開いた場合は、名前・アイコンとメールアドレス、参加した日時を SK Hub Systems に保存し、配信している開発者が参加している人を確かめたり外したりするためだけに使います（ほかの参加者には表示しません）。また、SK's Toolbox を LINE のミニアプリとして開いた場合は、LINE のプロフィール（名前・アイコン）を画面の表示にだけ使い、保存・送信しません。「LINE で送る」は、利用者が選んだ相手に、利用者の操作で LINE を通じて送ります。

第三条 アクセスチェックで取り扱う情報
1.本サイト（SK's Lab のツールを含みます。）、MALU、Nagi 及び Y-FILTER. の管理コンソールでは、不正な利用への対応と利用状況の把握のため、アクセスチェックを行います。
2.ブラウザの中に保存するもの：サポートID（ブラウザごとにランダムに作る識別子）、利用規約への同意状態、お知らせを表示したかどうか
3.SK Hub Systems に送信・保存するもの：サポートID、アクセスしたページの URL（「?」以降は含みません）、移動元サイトのドメイン、ブラウザの種類（ユーザーエージェント）、言語設定、アクセス日時、アクセス制限の判定結果
4.アクセスチェックでは、名前、メールアドレス、IP アドレスを記録しません。
5.「同意して閉じる」を選ぶまでの間、「同意しない」を選んだ場合、または同意を撤回した場合は、サーバーへの送信を行いません。
6.SK Hub Systems アカウントでログインしているときは、そのブラウザのサポートIDとタイムゾーンを、アカウントの利用の記録としても保存します（SK Hub Systems アカウント規約第三条及び第四条）。

第四条 お問い合わせで取り扱う情報
1.お問い合わせフォーム（https://sk-hub.jp/contact/）から送信された次の情報を、SK Hub Systems に保存します。
(a) お問い合わせの種類、対象のサービス、内容
(b) 返信先のメールアドレス（入力した場合のみ）
(c) サポートID、ブラウザの種類（ユーザーエージェント）、言語設定（「サポートIDとブラウザの情報を添える」を選んだ場合のみ）
(d) 送信日時
2.これらの情報は、お問い合わせへの対応のためにのみ利用します。読み取れるのは開発者だけです。

第四条の二 アクセス解析（Google アナリティクス）
1.本サイト（SK's Lab のツールを含みます。）、MALU 及び Nagi では、利用状況を把握して本サービスを改善するため、Google LLC の Google アナリティクスによるアクセス解析を行います。アクセス解析は、はじめて開いたときの案内でアクセス解析をオンにしたまま同意した場合（この案内のスイッチは、ブラウザのタイムゾーンが日本の場合は最初からオン、それ以外の場合は最初からオフです）、または表示される案内で「許可する」を選んだ場合に限り行います。選ぶまでの間や、許可しなかった場合は、Google アナリティクスを読み込みません。
2.許可した場合、Google アナリティクスは Cookie を使い、閲覧したページの URL とタイトル、移動元のページ、滞在時間、画面の大きさ、ブラウザ及び OS の種類、言語、おおまかな地域（国・地方程度）などを Google に送信します。IP アドレスは Google アナリティクスで匿名化され、開発者は、個人を特定できる形でこれらを受け取りません。
3.開発者は、Google シグナル及び広告のための機能を使いません。SK Hub Systems アカウントのページ、開発者用のページ及び同意の画面は、アクセス解析の対象にしません。MALU の検索語は送信しません。
4.許可は、本サイトの下にある「アクセス解析の設定」からいつでも取り消せます。取り消すと、以後の測定は行わず、ブラウザの中の Google アナリティクスの Cookie を削除します。
5.Google による情報の取り扱いについては、Google のプライバシーポリシー（https://policies.google.com/privacy）及び「Google のサービスを使用するサイトやアプリから収集した情報の Google による使用」（https://policies.google.com/technologies/partner-sites）をご覧ください。

第四条の三 Google のユーザーデータ（Google アカウントでのログイン）
1.SK Hub Systems アカウントに Google アカウントでログインした場合、開発者は Google から次の情報だけを受け取ります（Google のログインで求める範囲は openid・email・profile だけです。）。
(a) Google アカウントの識別子
(b) 名前
(c) メールアドレス
(d) プロフィール画像の URL
2.開発者は、Gmail、Google ドライブ、Google カレンダー、連絡先など、ほかの Google のサービスのデータにはアクセスしません。Google アカウントのパスワードも受け取りません。
3.第1項の情報は、次の目的にだけ使います。
(a) SK Hub Systems アカウントの作成とログイン（本人の確認）
(b) アカウントのページやサイトのヘッダーに、本人の名前とアイコンを表示すること
(c) 本人が選んで保存したデータ（設定の同期・MALU・Nagi・SK's Toolbox など）を、本人のアカウントに結び付けること
(d) SK's Toolbox の Timetable で、配信先として入力されたメールアドレスとログインした本人のメールアドレスを照らし合わせ、本人に時間割を表示すること
(e) 本アカウントのお知らせ（お問い合わせへの返事など）を本人に届けること
4.第1項の情報は、Google LLC の Firebase（Firebase Authentication 及び Cloud Firestore。Cloud Firestore のデータは東京リージョン）に保存し、通信は HTTPS で暗号化します。
5.開発者は、Google から受け取った情報を販売せず、広告やマーケティングに使わず、第三者に提供しません。人工知能・機械学習のモデルの開発や学習にも使いません。保存先の Firebase を提供する Google LLC による処理と、法令に基づく場合（第八条）を除き、ほかの者に渡しません。開発者が内容を見るのは、障害や不正な利用への対応、法令に基づく要請への対応、又は本人からの依頼による場合に限ります。
6.第1項の情報は、本アカウントを削除するまで保存します。本人は、https://sk-hub.jp/account/ から、保存されている情報をダウンロードでき、いつでも本アカウントを削除できます。削除すると、第1項の情報を含むアカウントの情報は削除されます。また、Google アカウントの設定（https://myaccount.google.com/connections）から、SK Hub Systems とのつながりを解除できます。2年以上ログインのない本アカウントは、開発者が削除する場合があります。
7.Google API から受け取った情報の利用及び他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（https://developers.google.com/terms/api-services-user-data-policy）に、限定的使用（Limited Use）の要件を含めて従います。

第五条 利用目的
1.本サービスの提供、維持及び改善
2.不正な利用や迷惑行為への対応（アクセスの制限を含みます。）
3.お問い合わせへの対応
4.重要なお知らせ

第六条 保存場所と安全管理
1.SK Hub Systems に保存する情報は、Google LLC の Firebase（Cloud Firestore 及び Firebase Authentication）に保存します。Cloud Firestore のデータは東京リージョンに保存されます。
2.通信は HTTPS により暗号化されます。アクセスチェックの記録とお問い合わせの内容を読み取れるのは開発者だけです。

第七条 保存期間
1.アクセスチェックの記録は、保存から1年を過ぎたものを順次削除します。
2.アクセス制限の情報は、制限を解除した時点で削除します。
3.お問い合わせの内容は、対応が終わってから1年を目安に削除します。
4.個別規約に保存期間の定めがある場合は、それに従います。
5.Google アナリティクスのデータは、Google アナリティクスの設定により、2か月を過ぎたものが削除されます。

第八条 第三者への提供
開発者は、法令に基づく場合を除き、取り扱う情報を第三者に提供しません。

第九条 外部サービス
本サービスは、次の外部サービスを利用しています。これらのサービスが、アクセスの際に IP アドレスなどを受け取ることがあります。その取り扱いは、各社のプライバシーポリシーに従います。
(a) GitHub Pages（本サイトの配信・GitHub, Inc.）
(b) Firebase（SK Hub Systems・Google LLC）
(c) Google Fonts（文字の表示・Google LLC）
(d) Google アナリティクス（アクセス解析・Google LLC。第四条の二のとおり、許可した場合のみ）
(e) Cloudflare Workers・D1（LINE・Kakao・パスキーでのログイン・Cloudflare, Inc.）
(f) LINE ログイン（LY株式会社）・Kakao ログイン（Kakao Corp.）（それぞれでログインする場合のみ）

第十条 未成年者の情報
本サービスは未成年者も利用することを想定しています。開発者は、必要以上の情報を取り扱わないよう努めます。

第十一条 情報の確認・削除
1.ブラウザのサイトデータを消去すると、ブラウザの中に保存した情報は削除されます。
2.SK Hub Systems アカウントの情報は、アカウントのページ（https://sk-hub.jp/account/）でダウンロード・削除できます。
3.そのほかにサーバーに保存した情報の確認や削除を希望する場合は、サポートID（本サイトのサポートページで確認できます）を添えて、お問い合わせページ（https://sk-hub.jp/contact/）からご連絡ください。

第十一条の二 欧州経済領域・英国などにお住まいの方
1.欧州経済領域（EEA）、英国、スイスなど、GDPR（EU 一般データ保護規則）やこれに類する法令が適用される地域にお住まいの方については、開発者（連絡先：https://sk-hub.jp/contact/）が情報の管理者となり、次の根拠に基づいて情報を取り扱います。
(a) アクセスチェック（第三条）：本サービスを安全に提供し、不正な利用を防ぐための開発者の正当な利益
(b) アクセス解析（第四条の二）：本人の同意
(c) お問い合わせ（第四条）：本人の求めに応じて対応するための開発者の正当な利益
(d) SK Hub Systems アカウント及び SK Hub Systems：各規約に基づくサービスの提供
2.これらの方は、法令の定めに従い、自分の情報の開示、訂正、削除、取り扱いの制限及びデータポータビリティ（持ち運び）を求め、また取り扱いに異議を述べることができます。同意に基づく取り扱いは、いつでも同意を撤回できます（撤回までの取り扱いには影響しません）。請求は、第十一条の方法で受け付けます。
3.これらの方は、お住まいの地域のデータ保護監督機関に苦情を申し立てることができます。
4.SK Hub Systems の情報は日本（Cloud Firestore の東京リージョン）に保存します。日本は、欧州委員会及び英国から、個人データの十分な保護水準を確保している国と認められています。Firebase Authentication、Google アナリティクス及び第九条の外部サービスでは、情報が米国など日本国外で取り扱われることがあり、各社は EU-米国データプライバシーフレームワークや標準契約条項などに基づく保護措置をとっています。

第十二条 変更
本ポリシーを変更する場合は、本サイトに掲載してお知らせします。取り扱う情報を増やすなど重要な変更の場合は、改めて同意をお願いします。
