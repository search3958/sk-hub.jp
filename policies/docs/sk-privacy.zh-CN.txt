SK 隐私政策
制定日期：2026年9月25日

第一条 基本方针
1.SK（以下称“开发者”）在 SK 使用条款规定的本服务中，按照本政策处理用户的信息。
2.开发者仅在提供本服务所需的范围内处理信息。所处理的信息绝不用于广告、出售、提供给第三方或追踪本服务以外的行为。第四条之二的访问分析仅针对允许的人进行。
3.Y-FILTER.、SK Hub Systems 及 SK Hub Systems 账户中信息处理的详细内容，由“Y-FILTER. 使用条款及隐私政策”“SK Hub Systems 使用条款”及“SK Hub Systems 账户条款”规定。如与本政策内容不同，就该服务而言以各自的规定为准。

第二条 各服务概要
(a) 本网站（包括 SK's Lab 的工具）、MALU、Nagi、Y-FILTER. 的管理控制台：处理第三条所述访问检查的信息。MALU 的搜索词、搜索记录和设置只保存在浏览器中，不会发送。但是，使用 SK Hub Systems 账户登录时，将按照 SK Hub Systems 账户条款的规定同步 MALU 的设置；连接 MALU 后，保存到单词本的词语、以及开启搜索记录同步时的搜索记录，将保存到本人的账户中。
(b) Y-FILTER.：过滤在浏览器内进行，不会将浏览记录和搜索词发送给开发者。
(c) SK Hub Systems：仅在使用 Y-FILTER. 远程管理功能，或将 Y-FILTER. 作为自己的设备连接到 SK Hub Systems 账户时，保存设置内容、设备状态和设置备份等。
(d) 咨询：将咨询表单中填写的内容保存在 SK Hub Systems 中。
(e) SK Hub Systems 账户：仅在创建账户时，保存用于登录的账号（Google、GitHub、LINE、Kakao）信息（标识符、姓名、头像；Google、GitHub 还包括邮箱地址；不从 LINE、Kakao 获取邮箱地址；注册通行密钥时为其公钥等，不获取指纹、面部等信息）以及同意条款的日期等。登录后使用的浏览器的时区（大致地区）和支持 ID 也会作为使用记录保存。
(f) Nagi：专注记录（开始专注的时间和专注的时长）及设置只保存在浏览器中，不会发送。但是，使用 SK Hub Systems 账户连接 Nagi 后，专注记录和每日目标将保存到本人的账户中。不会记录学习的内容或浏览的网站。
(g) SK's Toolbox：Clock、Calc、Memo、Todo、Countdown、Timetable、Roulette 的数据及设置只保存在浏览器中，不会发送。但是，使用 SK Hub Systems 账户连接 SK's Toolbox 并开始在线同步后，所选应用的数据会在设备上使用本人设定的同步密码短语加密后，保存到本人的账户中。解密密钥只存在于本人的设备中，开发者无法读取其内容。Memo 的图片不会发送。此外，开发者使用 Timetable 发送课程表时，开发者作为接收者输入的邮箱地址和发送的课程表会保存到 SK Hub Systems，仅用于向使用该邮箱地址的 SK Hub Systems 账户登录的本人显示课程表。接收者之间互相看不到，停止发送后即删除。使用邀请码加入发送时，或接收者打开发送的课程表时，名字、头像、邮箱地址及加入的日期时间会保存到 SK Hub Systems，仅用于发送课程表的开发者确认或移除已加入的人（其他成员看不到）。此外，将 SK's Toolbox 作为 LINE 迷你应用打开时，LINE 的个人资料（名称·头像）仅用于画面显示，不会保存或发送。“用 LINE 发送”仅在用户操作时，通过 LINE 发送给用户选择的对象。

第三条 访问检查中处理的信息
1.在本网站（包括 SK's Lab 的工具）、MALU、Nagi 及 Y-FILTER. 的管理控制台中，为应对不当使用和了解使用情况，会进行访问检查。
2.保存在浏览器中的信息：支持 ID（为每个浏览器随机生成的标识符）、使用条款的同意状态、是否已显示通知
3.发送并保存到 SK Hub Systems 的信息：支持 ID、访问页面的网址（不含“?”之后的部分）、来源网站的域名、浏览器类型（用户代理）、语言设置、访问日期时间、访问限制的判定结果
4.访问检查不记录姓名、邮箱地址和 IP 地址。
5.在选择“同意并关闭”之前、选择“不同意”时，或撤回同意时，不会向服务器发送信息。
6.使用 SK Hub Systems 账户登录时，该浏览器的支持 ID 和时区也会作为账户的使用记录保存（SK Hub Systems 账户条款第三条及第四条）。

第四条 咨询中处理的信息
1.通过咨询表单（https://sk-hub.jp/contact/）发送的以下信息，保存在 SK Hub Systems 中：
(a) 咨询类型、相关服务、内容
(b) 回复邮箱地址（仅在填写时）
(c) 支持 ID、浏览器类型（用户代理）、语言设置（仅在选择“附上支持 ID 和浏览器信息”时）
(d) 发送日期时间
2.这些信息仅用于处理咨询，只有开发者可以阅读。

第四条之二 访问分析（Google Analytics）
1.本网站（包括 SK's Lab 的工具）、MALU 及 Nagi 为了解使用情况并改进本服务，会使用 Google LLC 的 Google Analytics 进行访问分析。仅在首次打开时的提示中保持访问分析开启并同意（若浏览器的时区为日本，该提示中的开关默认开启，否则默认关闭），或在显示的提示中选择“允许”时进行访问分析。在选择之前或不允许时，不会加载 Google Analytics。
2.允许后，Google Analytics 会使用 Cookie，将浏览页面的网址和标题、来源页面、停留时间、屏幕尺寸、浏览器及操作系统的类型、语言、大致地区（国家或地区级别）等发送给 Google。IP 地址会由 Google Analytics 匿名化，开发者不会以可识别个人的形式接收这些信息。
3.开发者不使用 Google 信号及用于广告的功能。SK Hub Systems 账户页面、开发者用页面及同意画面不属于访问分析的对象。不会发送 MALU 的搜索词。
4.可以随时通过本网站下方的“访问分析设置”撤回允许。撤回后将不再进行测量，并删除浏览器中 Google Analytics 的 Cookie。
5.关于 Google 对信息的处理，请参阅 Google 隐私政策（https://policies.google.com/privacy）及“Google 如何使用来自使用其服务的网站或应用的信息”（https://policies.google.com/technologies/partner-sites）。

第四条之三 Google 用户数据（使用 Google 账号登录）
1.使用 Google 账号登录 SK Hub Systems 账号时，开发者只从 Google 接收以下信息（Google 登录只请求 openid、email、profile 范围）。
(a) Google 账号的标识符
(b) 姓名
(c) 电子邮件地址
(d) 头像图片的 URL
2.开发者不会访问 Gmail、Google 云端硬盘、Google 日历、通讯录等其他 Google 服务的数据，也不会接收 Google 账号的密码。
3.第1款的信息仅用于以下目的。
(a) 创建 SK Hub Systems 账号及登录（确认本人）
(b) 在账号页面和网站顶部显示本人的姓名和头像
(c) 将本人选择保存的数据（设置同步、MALU、Nagi、SK's Toolbox 等）关联到本人的账号
(d) 在 SK's Toolbox 的 Timetable 中，将作为接收者输入的电子邮件地址与已登录本人的电子邮件地址进行核对，并向本人显示课程表
(e) 向本人发送本账号的通知（如对咨询的回复）
4.第1款的信息保存在 Google LLC 的 Firebase（Firebase Authentication 及 Cloud Firestore。Cloud Firestore 的数据保存在东京区域），通信通过 HTTPS 加密。
5.开发者不会出售从 Google 接收的信息，不会将其用于广告或营销，也不会提供给第三方。也不会将其用于开发或训练人工智能、机器学习模型。除提供 Firebase 的 Google LLC 进行的处理及依据法律的情况（第八条）外，不会交给其他人。开发者仅在应对故障或不正当使用、应对依法提出的要求或应本人请求时查看其内容。
6.第1款的信息保存至本账号被删除为止。本人可在 https://sk-hub.jp/account/ 下载已保存的信息，并可随时删除本账号。删除后，包括第1款信息在内的账号信息将被删除。此外，也可在 Google 账号的设置（https://myaccount.google.com/connections）中解除与 SK Hub Systems 的关联。2年以上未登录的本账号，开发者可能会将其删除。
7.对从 Google API 接收的信息的使用及向其他应用的转移，将遵守 Google API 服务用户数据政策（https://developers.google.com/terms/api-services-user-data-policy），包括有限使用（Limited Use）的要求。

第五条 使用目的
1.本服务的提供、维护及改进
2.应对不当使用和骚扰行为（包括访问限制）
3.处理咨询
4.重要通知

第六条 保存地点与安全管理
1.保存在 SK Hub Systems 中的信息，保存于 Google LLC 的 Firebase（Cloud Firestore 及 Firebase Authentication）。Cloud Firestore 的数据保存在东京区域。
2.通信通过 HTTPS 加密。访问检查记录和咨询内容只有开发者可以阅读。

第七条 保存期限
1.访问检查记录在保存超过 1 年后依次删除。
2.访问限制的信息在解除限制时删除。
3.咨询内容在处理完毕后约 1 年删除。
4.如单独条款对保存期限另有规定，则从其规定。
5.Google Analytics 的数据将根据 Google Analytics 的设置，删除超过 2 个月的数据。

第八条 向第三方提供
除依据法律法规的情形外，开发者不会向第三方提供所处理的信息。

第九条 外部服务
本服务使用以下外部服务。这些服务在访问时可能会获取 IP 地址等信息，其处理遵循各公司的隐私政策。
(a) GitHub Pages（本网站的托管、GitHub, Inc.）
(b) Firebase（SK Hub Systems、Google LLC）
(c) Google Fonts（文字显示、Google LLC）
(d) Google Analytics（访问分析・Google LLC。按照第四条之二，仅限允许时）
(e) Cloudflare Workers・D1（LINE・Kakao・通行密钥登录、Cloudflare, Inc.）
(f) LINE 登录（LY Corporation）・Kakao 登录（Kakao Corp.）（仅限使用各自登录时）

第十条 未成年人的信息
本服务预计也会由未成年人使用。开发者会努力不处理超出必要范围的信息。

第十一条 信息的确认与删除
1.清除浏览器的网站数据后，保存在浏览器中的信息将被删除。
2.SK Hub Systems 账户的信息可以在账户页面（https://sk-hub.jp/account/）下载和删除。
3.如希望确认或删除保存在服务器上的其他信息，请附上支持 ID（可在本网站的支持页面查看），通过联系页面（https://sk-hub.jp/contact/）与我们联系。

第十一条之二 居住在欧洲经济区、英国等地区的用户
1.对于居住在欧洲经济区（EEA）、英国、瑞士等适用 GDPR（欧盟《通用数据保护条例》）或类似法律的地区的用户，开发者（联系方式：https://sk-hub.jp/contact/）是信息的控制者，并基于以下依据处理信息。
(a) 访问检查（第三条）：为安全提供本服务、防止不当使用而具有的开发者的正当利益
(b) 访问分析（第四条之二）：本人的同意
(c) 咨询（第四条）：为回应本人请求而具有的开发者的正当利益
(d) SK Hub Systems 账户及 SK Hub Systems：依据各条款提供服务
2.这些用户可依据法律规定，要求查阅、更正、删除自己的信息，限制处理以及数据可携带，并可对处理提出异议。对于基于同意的处理，可随时撤回同意（不影响撤回前的处理）。请求按第十一条的方式受理。
3.这些用户可以向所在地区的数据保护监管机构投诉。
4.SK Hub Systems 的信息保存在日本（Cloud Firestore 的东京区域）。日本已被欧盟委员会及英国认定为能确保个人数据充分保护水平的国家。在 Firebase Authentication、Google Analytics 及第九条的外部服务中，信息可能会在美国等日本以外的地方处理，各公司均依据欧盟-美国数据隐私框架、标准合同条款等采取了保护措施。

第十二条 变更
变更本政策时，将在本网站发布通知。如属于增加所处理信息等重要变更，将重新征求同意。
