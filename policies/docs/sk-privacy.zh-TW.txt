SK 隱私權政策
制定日期：2026年9月25日

第一條 基本方針
1.SK（以下稱「開發者」）於 SK 使用條款所定的本服務中，依本政策處理使用者的資訊。
2.開發者僅在提供本服務所需的範圍內處理資訊。所處理的資訊絕不用於廣告、販售、提供給第三方或追蹤本服務以外的行為。第四條之二的存取分析僅針對允許的人進行。
3.Y-FILTER.、SK Hub Systems 及 SK Hub Systems 帳戶中資訊處理的詳細內容，由「Y-FILTER. 使用條款及隱私權政策」「SK Hub Systems 使用條款」及「SK Hub Systems 帳戶條款」規定。如與本政策內容不同，就該服務而言以各自的規定為準。

第二條 各服務概要
(a) 本網站（包括 SK's Lab 的工具）、MALU、Nagi、Y-FILTER. 的管理主控台：處理第三條所述存取檢查的資訊。MALU 的搜尋字詞、搜尋紀錄和設定只儲存在瀏覽器中，不會傳送。但是，使用 SK Hub Systems 帳戶登入時，將依 SK Hub Systems 帳戶條款的規定同步 MALU 的設定；連接 MALU 後，儲存到單字本的詞語、以及開啟搜尋紀錄同步時的搜尋紀錄，將儲存到本人的帳戶中。
(b) Y-FILTER.：過濾在瀏覽器內進行，不會將瀏覽紀錄和搜尋字詞傳送給開發者。
(c) SK Hub Systems：僅於使用 Y-FILTER. 遠端管理功能，或將 Y-FILTER. 作為自己的裝置連接到 SK Hub Systems 帳戶時，儲存設定內容、裝置狀態和設定備份等。
(d) 聯絡：將聯絡表單中填寫的內容儲存在 SK Hub Systems 中。
(e) SK Hub Systems 帳戶：僅於建立帳戶時，儲存用於登入的帳戶（Google、GitHub、LINE、Kakao）資訊（識別碼、姓名、大頭貼；Google、GitHub 另含電子郵件地址；不從 LINE、Kakao 取得電子郵件地址；註冊通行金鑰時為其公開金鑰等，不取得指紋、臉部等資訊）以及同意條款的日期等。登入後使用的瀏覽器的時區（大致地區）和支援 ID 也會作為使用紀錄儲存。
(f) Nagi：專注記錄（開始專注的時間和專注的時長）及設定只儲存在瀏覽器中，不會傳送。但是，使用 SK Hub Systems 帳戶連接 Nagi 後，專注記錄和每日目標將儲存到本人的帳戶中。不會記錄學習的內容或瀏覽的網站。
(g) SK's Toolbox：Clock、Calc、Memo、Todo、Countdown、Timetable、Roulette 的資料及設定只儲存在瀏覽器中，不會傳送。但是，使用 SK Hub Systems 帳戶連接 SK's Toolbox 並開始線上同步後，所選應用程式的資料會在裝置上以本人設定的同步密碼片語加密後，儲存到本人的帳戶中。解密金鑰只存在於本人的裝置中，開發者無法讀取其內容。Memo 的圖片不會傳送。此外，開發者使用 Timetable 傳送課表時，開發者作為接收者輸入的電子郵件地址和傳送的課表會儲存到 SK Hub Systems，僅用於向使用該電子郵件地址的 SK Hub Systems 帳戶登入的本人顯示課表。接收者之間互相看不到，停止傳送後即刪除。使用邀請碼加入傳送時，或接收者開啟傳送的課表時，名字、頭像、電子郵件地址及加入的日期時間會儲存到 SK Hub Systems，僅用於傳送課表的開發者確認或移除已加入的人（其他成員看不到）。此外，將 SK's Toolbox 作為 LINE 迷你應用程式開啟時，LINE 的個人檔案（名稱·大頭貼）僅用於畫面顯示，不會儲存或傳送。「用 LINE 傳送」僅在使用者操作時，透過 LINE 傳送給使用者選擇的對象。

第三條 存取檢查中處理的資訊
1.在本網站（包括 SK's Lab 的工具）、MALU、Nagi 及 Y-FILTER. 的管理主控台中，為因應不當使用及掌握使用情況，會進行存取檢查。
2.儲存在瀏覽器中的資訊：支援 ID（為每個瀏覽器隨機產生的識別碼）、使用條款的同意狀態、是否已顯示通知
3.傳送並儲存至 SK Hub Systems 的資訊：支援 ID、存取頁面的網址（不含「?」之後的部分）、來源網站的網域、瀏覽器類型（使用者代理程式）、語言設定、存取日期時間、存取限制的判定結果
4.存取檢查不記錄姓名、電子郵件地址和 IP 位址。
5.在選擇「同意並關閉」之前、選擇「不同意」時，或撤回同意時，不會向伺服器傳送資訊。
6.使用 SK Hub Systems 帳戶登入時，該瀏覽器的支援 ID 和時區也會作為帳戶的使用紀錄儲存（SK Hub Systems 帳戶條款第三條及第四條）。

第四條 聯絡中處理的資訊
1.透過聯絡表單（https://sk-hub.jp/contact/）傳送的以下資訊，儲存在 SK Hub Systems 中：
(a) 聯絡類型、相關服務、內容
(b) 回覆用電子郵件地址（僅於填寫時）
(c) 支援 ID、瀏覽器類型（使用者代理程式）、語言設定（僅於選擇「附上支援 ID 和瀏覽器資訊」時）
(d) 傳送日期時間
2.這些資訊僅用於處理聯絡事項，只有開發者可以閱讀。

第四條之二 存取分析（Google Analytics）
1.本網站（包括 SK's Lab 的工具）、MALU 及 Nagi 為了解使用情況並改進本服務，會使用 Google LLC 的 Google Analytics 進行存取分析。僅在首次開啟時的提示中保持存取分析開啟並同意（若瀏覽器的時區為日本，該提示中的開關預設開啟，否則預設關閉），或在顯示的提示中選擇「允許」時進行存取分析。在選擇之前或不允許時，不會載入 Google Analytics。
2.允許後，Google Analytics 會使用 Cookie，將瀏覽頁面的網址和標題、來源頁面、停留時間、螢幕尺寸、瀏覽器及作業系統的類型、語言、大致地區（國家或地區層級）等傳送給 Google。IP 位址會由 Google Analytics 匿名化，開發者不會以可識別個人的形式接收這些資訊。
3.開發者不使用 Google 信號及用於廣告的功能。SK Hub Systems 帳戶頁面、開發者用頁面及同意畫面不屬於存取分析的對象。不會傳送 MALU 的搜尋字詞。
4.可以隨時透過本網站下方的「存取分析設定」撤回允許。撤回後將不再進行測量，並刪除瀏覽器中 Google Analytics 的 Cookie。
5.關於 Google 對資訊的處理，請參閱 Google 隱私權政策（https://policies.google.com/privacy）及「Google 如何使用來自使用其服務的網站或應用程式的資訊」（https://policies.google.com/technologies/partner-sites）。

第四條之三 Google 使用者資料（使用 Google 帳號登入）
1.使用 Google 帳號登入 SK Hub Systems 帳號時，開發者只從 Google 接收以下資訊（Google 登入只要求 openid、email、profile 範圍）。
(a) Google 帳號的識別碼
(b) 姓名
(c) 電子郵件地址
(d) 個人資料相片的 URL
2.開發者不會存取 Gmail、Google 雲端硬碟、Google 日曆、聯絡人等其他 Google 服務的資料，也不會接收 Google 帳號的密碼。
3.第1項的資訊僅用於以下目的。
(a) 建立 SK Hub Systems 帳號及登入（確認本人）
(b) 在帳號頁面和網站頂部顯示本人的姓名和圖示
(c) 將本人選擇儲存的資料（設定同步、MALU、Nagi、SK's Toolbox 等）連結到本人的帳號
(d) 在 SK's Toolbox 的 Timetable 中，將作為接收者輸入的電子郵件地址與已登入本人的電子郵件地址進行核對，並向本人顯示課表
(e) 向本人傳送本帳號的通知（如對詢問的回覆）
4.第1項的資訊儲存在 Google LLC 的 Firebase（Firebase Authentication 及 Cloud Firestore。Cloud Firestore 的資料儲存在東京區域），通訊透過 HTTPS 加密。
5.開發者不會出售從 Google 接收的資訊，不會將其用於廣告或行銷，也不會提供給第三方。也不會將其用於開發或訓練人工智慧、機器學習模型。除提供 Firebase 的 Google LLC 進行的處理及依法令的情況（第八條）外，不會交給其他人。開發者僅在處理故障或不當使用、回應依法提出的要求或應本人要求時查看其內容。
6.第1項的資訊保存至本帳號被刪除為止。本人可在 https://sk-hub.jp/account/ 下載已儲存的資訊，並可隨時刪除本帳號。刪除後，包括第1項資訊在內的帳號資訊將被刪除。此外，也可在 Google 帳號的設定（https://myaccount.google.com/connections）中解除與 SK Hub Systems 的連結。2年以上未登入的本帳號，開發者可能會將其刪除。
7.對從 Google API 接收的資訊的使用及向其他應用程式的轉移，將遵守 Google API 服務使用者資料政策（https://developers.google.com/terms/api-services-user-data-policy），包括有限使用（Limited Use）的要求。

第五條 使用目的
1.本服務的提供、維護及改善
2.因應不當使用和騷擾行為（包括存取限制）
3.處理聯絡事項
4.重要通知

第六條 儲存地點與安全管理
1.儲存在 SK Hub Systems 中的資訊，儲存於 Google LLC 的 Firebase（Cloud Firestore 及 Firebase Authentication）。Cloud Firestore 的資料儲存在東京區域。
2.通訊以 HTTPS 加密。存取檢查紀錄和聯絡內容只有開發者可以閱讀。

第七條 保存期限
1.存取檢查紀錄於儲存超過 1 年後依序刪除。
2.存取限制的資訊於解除限制時刪除。
3.聯絡內容於處理完畢後約 1 年刪除。
4.如個別條款對保存期限另有規定，則從其規定。
5.Google Analytics 的資料將依 Google Analytics 的設定，刪除超過 2 個月的資料。

第八條 提供給第三方
除依據法令的情形外，開發者不會將所處理的資訊提供給第三方。

第九條 外部服務
本服務使用以下外部服務。這些服務在存取時可能會取得 IP 位址等資訊，其處理依各公司的隱私權政策。
(a) GitHub Pages（本網站的代管、GitHub, Inc.）
(b) Firebase（SK Hub Systems、Google LLC）
(c) Google Fonts（文字顯示、Google LLC）
(d) Google Analytics（存取分析・Google LLC。依第四條之二，僅限允許時）
(e) Cloudflare Workers・D1（LINE・Kakao・通行金鑰登入、Cloudflare, Inc.）
(f) LINE 登入（LY Corporation）・Kakao 登入（Kakao Corp.）（僅限使用各自登入時）

第十條 未成年人的資訊
本服務預期也會由未成年人使用。開發者會努力不處理超出必要範圍的資訊。

第十一條 資訊的確認與刪除
1.清除瀏覽器的網站資料後，儲存在瀏覽器中的資訊將被刪除。
2.SK Hub Systems 帳戶的資訊可以在帳戶頁面（https://sk-hub.jp/account/）下載和刪除。
3.如希望確認或刪除儲存在伺服器上的其他資訊，請附上支援 ID（可在本網站的支援頁面查看），透過聯絡頁面（https://sk-hub.jp/contact/）與我們聯繫。

第十一條之二 居住在歐洲經濟區、英國等地區的使用者
1.對於居住在歐洲經濟區（EEA）、英國、瑞士等適用 GDPR（歐盟《一般資料保護規則》）或類似法律的地區的使用者，開發者（聯絡方式：https://sk-hub.jp/contact/）是資訊的控管者，並基於以下依據處理資訊。
(a) 存取檢查（第三條）：為安全提供本服務、防止不當使用而具有的開發者的正當利益
(b) 存取分析（第四條之二）：本人的同意
(c) 聯絡（第四條）：為回應本人請求而具有的開發者的正當利益
(d) SK Hub Systems 帳戶及 SK Hub Systems：依據各條款提供服務
2.這些使用者可依據法律規定，要求查閱、更正、刪除自己的資訊，限制處理以及資料可攜，並可對處理提出異議。對於基於同意的處理，可隨時撤回同意（不影響撤回前的處理）。請求依第十一條的方式受理。
3.這些使用者可以向所在地區的資料保護監管機關申訴。
4.SK Hub Systems 的資訊儲存在日本（Cloud Firestore 的東京區域）。日本已被歐盟執委會及英國認定為能確保個人資料充分保護水準的國家。在 Firebase Authentication、Google Analytics 及第九條的外部服務中，資訊可能會在美國等日本以外的地方處理，各公司均依據歐盟-美國資料隱私框架、標準契約條款等採取了保護措施。

第十二條 變更
變更本政策時，將於本網站公布通知。如屬增加所處理資訊等重要變更，將重新徵求同意。
