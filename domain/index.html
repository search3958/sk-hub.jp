SK のサイトは、
sk-hub.jp に引っ越します

SK のサイトとプロダクトのアドレスを、いまの sy9-k.github.io から、新しいドメイン sk-hub.jp に変更します。アドレスの「/」から後ろはそのままです。

いま sy9-k.github.io/toolbox/
これから sk-hub.jp/toolbox/
スケジュール

いつ変わるの？

2026年10月14日（水）12:00 に、sk-hub.jp で公開しました。いまは移行期間です。

  1. 10月13日まで 準備

    新しいドメインの手続きと、引っ越しの準備をしました。

  2. いま（10月14日 12:00〜） sk-hub.jp で公開

    サイトとプロダクトが sk-hub.jp で開けるようになりました。このあいだは sy9-k.github.io もそのまま使えますが、更新は止まっています。

  3. 移行期間の終わり 古いアドレスは引っ越し専用に

    sy9-k.github.io では、端末のデータを新しいアドレスへ移すページだけを出します。データを移したら、sk-hub.jp の同じページに進めます。

  4. そのあと 古いアドレスは使われなくなります

    sy9-k.github.io は使われなくなり、sk-hub.jp へのご案内だけを出します。

これからできること

新しくできるようになること

SK だけのドメインを持つことで、これまでできなかったことができるようになります。引っ越しのあと、準備ができたものから順にはじめます。

覚えやすく、変わらないアドレス

「sk-hub.jp」だけで、すべてのサービスにたどり着けます。チラシや QR コードに載せたアドレスも、この先ずっと使えます。

ログインの画面に SK の名前

Google でログインするときの画面に、いまの「y-filter-systems.firebaseapp.com」ではなく、SK のアドレスが出るようになります。どこにログインするのかが、ひと目でわかります。

パスキーでログイン

パスワードを使わずに、指紋や顔、端末のロックの解除だけで SK Hub Systems アカウントにログインできるようにします。パスキーはドメインに結びつくため、引っ越しのあとに用意します。

LINE とつながる

LINE でのログインや、LINE の中の SK's Toolbox で SK Hub Systems アカウントの同期を使えるようにします。時間割の連絡などを、SK Hub の公式 LINE で受け取れるようにすることも考えています。

SK のメールアドレス

お問い合わせの返信やお知らせを、sk-hub.jp のメールアドレスからお送りします。SK からの本物のメールかどうかを、アドレスで見分けられます。

もっと便利な通知と自動の処理

SK 専用の小さなサーバーを sk-hub.jp に置けるようになります。決まった時間のお知らせや、お問い合わせの受け付けなど、ブラウザだけではできなかったことに使います。

変わらないこと

そのまま使えるもの

SK Hub Systems アカウント

アカウントはそのままです。Google・GitHub でのログインも、同期しているデータも引き継がれます。新しいアドレスで、もう一度ログインするだけです。

サービスの中身と料金

使える機能は変わりません。これまでどおり無料です。利用規約とプライバシーポリシーは、アドレスの記載だけを新しくします。

リンクと招待

古いアドレスのリンク・時間割の招待リンクも、移行期間が終わったあとは、新しいアドレスの同じページに案内するので、そのまま使えます。

LINE で使う SK's Toolbox

LINE のミニアプリは、これまでのリンクのまま使えます。

お願い

切り替えのときにしてほしいこと

ブラウザは、端末に保存するデータやログインの状態を、アドレスごとに分けて持っています。そのため、新しいアドレスでは、いくつかやり直しが必要です。

端末に保存しているデータを移す

SK's Toolbox（Todo・Memo・時間割など）、Nagi の記録、MALU の単語帳など、端末にだけ保存しているデータは、新しいアドレスでは最初は空になります。

  • SK Hub Systems で同期している人 … 新しいアドレスでログインすると戻ります。SK's Toolbox の同期を使っている人は、同期用のパスフレーズの入力も必要なので、控えておいてください。
  • 同期していない人 … 切り替えのときに、データをそのまま移す「引っ越し」の機能を用意する予定です。念のため、SK's Toolbox の設定の「まとめてバックアップ」で書き出しておくと安心です（Memo の画像も入ります）。
  • これから同期する人 … 移行期間のあいだに、古いアドレスで SK Hub Systems アカウントにログインして同期をオンにしておくと、新しいアドレスでログインするだけで戻ります。

アプリとして入れている人は、入れ直す

SK's Toolbox・Nagi・MALU をホーム画面やパソコンにアプリとして入れている人は、新しいアドレスで入れ直してください。古いアプリを開くと、入れ直しの案内を出します。

ブックマークを新しくする

古いアドレスは更新が止まり、いずれ使えなくなります。ブックマークやホーム画面のリンクは、新しいアドレスに登録し直してください。

もう一度ログインする

SK Hub Systems アカウントのログインの状態は引き継がれません。新しいアドレスで、いつもの Google か GitHub のアカウントでログインしてください。

Y-FILTER. は自動で更新

ブラウザ拡張機能の Y-FILTER. は、新しいアドレスに対応した版に自動で更新されます。とくに操作はいりません。

似たアドレスに気をつけてください

SK の公式のアドレスは、sk-hub.jp（とその下のアドレス）と、引っ越しが終わるまでの sy9-k.github.io だけです。skhub.jp・sk-hub.com など、よく似たアドレスは SK とは関係ありません。SK が、メールや SNS でパスワードや個人情報を聞くことはありません。

よくある質問

気になること

どうしてアドレスを変えるのですか？

いまのアドレスは、サイトを置いている GitHub のアカウント名から決まっています。SK のサービスにあった、覚えやすく、ずっと変わらないアドレスで届けるために、独自のドメインに移ります。Google のログイン画面に出るアドレスや、お問い合わせのメールアドレスも、SK のものにそろえていく予定です。

古いアドレスは、いつまで使えますか？

切り替えのあと、移行期間のあいだはそのまま使えます（新しい機能や修正は入りません）。移行期間が終わると、端末のデータを移すページだけになり、そのあと使われなくなります。それぞれの時期は、前もってお知らせします。

移行期間のあいだ、古いアドレスで使い続けてもいいですか？

使えますが、できるだけ早めに新しいアドレスに移ってください。両方のアドレスで使うと、端末のデータが 2 つに分かれてしまいます。

何もしないと、データは消えますか？

古いアドレスの端末のデータは、すぐには消えません。ただし、新しいアドレスからは見えないので、同期・引っ越しの機能・まとめてバックアップのどれかで移してください。

料金はかかりますか？

かかりません。SK のサービスは、引っ越しのあとも無料です。

わからないことがあれば、お問い合わせからご連絡ください。
