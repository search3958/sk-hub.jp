アプリとして入れるとできること

すぐ開けるホーム画面・Dock のアイコンから。ブラウザのタブに埋もれません

よくある質問

お金はかかりますか？

かかりません。アプリストアも、アカウントもいりません。

アプリごとに入れることはできますか？

できます。Clock だけ、Todo だけなど、そのアプリを開いてから同じ手順で入れると、そのアプリだけが入ります。SK's Toolbox を入れると、全部のアプリがその中で使えます。

新しくなったら、入れ直しが必要ですか？

いりません。開いたときに自動で新しい版を確かめて、「新しくなりました」と出たら「更新」を押すだけです。

データはどこに保存されますか？

この端末の中だけです。オンライン同期（任意）をオンにしたときだけ、端末で暗号化してから SK Hub Systems アカウントに保存します。

消すには？

iPhone・iPad・Android は、アイコンを長押しして「削除」（「アンインストール」）。パソコンは、アプリのウィンドウの右上の「…」から「アンインストール」です。

アプリを消すと、その中のデータも消えることがあります。先に各アプリの「バックアップを書き出す」をしておくと安心です。
